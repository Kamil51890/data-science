# Репозиторий с практическими работами по Data-scince от базjвой работы с pandas до deep learning и анализу данных

## Содержание:
 - Pandas_1.ipynb - эта моя первая практическая работа для того чтобы понять основы pandas и matplotlib
    **Датасет:** `BankChurnersRAW.csv` — данные клиентов банка по кредитным картам
      (10 127 строк, 19 столбцов). Цель — `Churn` (отток клиентов: 1 — ушёл, 0 — остался).
      Файл в кодировке cp1251, разделитель `;`.
   
     Стек технологий которые использовал:
       -Python
       -Pandas (для анализа, выявления аномалий, подготовки данных, очистки данных)
       -Matpotlib (Испльзовал для визуализации уже подготовленнх данных)
       -PyMystem (Использовал для того чтобы леммитизации категории purpose)

   **Что сделано:**
      - загрузка и первичный осмотр данных, проверка типов и пропусков;
      - анализ пропусков в `YearIncome` (985 значений) и выбор способа обработки;
      - поиск дубликатов и аномальных значений;
      - лемматизация текстового признака `Purpose` (38 формулировок) с помощью `pymystem3`
        и приведение их к общим категориям;
      - визуализация подготовленных данных в `matplotlib`.
